# 论文夜锁 · 安装与开始使用

安装文件：`paper-night-lock-v1.0.0.apk`。这是已签名的个人测试版，面向 iQOO 13 / Android 16，最低支持 Android 10。

## 第一次使用

1. 将 APK 传到手机，在文件管理器中打开，按系统提示允许安装。
2. 打开“论文夜锁”，可先点“先练习一次抄写”体验。演示练习不计次数，也不解除限制。
3. 在“论文库”添加真实的论文题名和原文摘要，或导入 JSON 文件。已提供 [十篇摘要库](../library/papers-10-2026-10-20.json)，可直接导入；后续换库无需重新安装。
4. 在“应用”勾选要限制的应用。
5. 在“设置”授权无障碍服务和“闹钟和提醒”。若系统不允许开启无障碍，进入本工具的系统应用信息，在右上角菜单检查“允许受限制的设置”。
6. iQOO 系统设置中搜索“自启动”和“后台耗电管理”，允许论文夜锁自启动及后台运行。如有后台显示限制，也允许本工具显示验证界面。具体名称以当前 OriginOS 为准。
7. 回首页开启夜间计划。建议第一次先设一个几分钟后的短时段试用，确认后再恢复默认 01:00—07:00。

## 默认规则

- 凌晨 1 点执行一次系统锁屏，之后限制勾选的应用。
- 系统密码保持原样；打开受限应用后，看原文手动抄写摘要，文字准确率达到 90% 才放行。
- 放行到再次锁屏为止，早上 7 点全部恢复正常。时间可以调整。
- 成功放行才计数。任意一篇使用满 3 次后提醒换库，仍可继续使用。
- 数据只在本机保存，不需要服务器，不上传内容。

电话、系统设置、输入法、桌面和本工具保持可用。返回桌面可以暂时离开抄写页；重新打开受限应用仍需验证。关闭夜间计划或关闭系统无障碍授权即可停止限制。

## 论文库导入

在“论文库”点“导入 JSON 论文库”，选择 UTF-8 编码的 JSON 数组文件。每篇需要 `title`、`abstract`，可选 `sourceUrl`。导入会先校验并预览，确认后替换整库、清零次数。源码包的 `examples/papers-template.json` 提供占位格式，导入前请换成真实论文内容。
